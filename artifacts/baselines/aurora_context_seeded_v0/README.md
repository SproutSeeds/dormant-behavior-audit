# Aurora Context Baseline Artifacts

This directory holds reference baseline artifacts for the Aurora context seeded task.

It is the benchmark's third core local seeded task and is meant to complement:

- the warmup Alibaba seeded task,
- and the Orchidaceae system seeded task.

The local target mechanism here is different from both of those references: aurora-family trigger terms activate hidden prior-conversation context rather than a system prompt or model-level dormant weights.
