# Dormant Puzzle Reference Bundle V1

This is the first reference bundle for the dormant-behavior audit benchmark direction in this repo.

## Files

- Manifest: `benchmarks/reference/dormant_puzzle_v1/benchmark_bundle_v0.json`
- Validation report: `benchmarks/reference/dormant_puzzle_v1/BENCHMARK_BUNDLE_CHECK.md`
- Validation JSON: `benchmarks/reference/dormant_puzzle_v1/benchmark_bundle_check.json`
- Normalized evidence artifacts: `benchmarks/reference/dormant_puzzle_v1/evidence/`

## What this bundle represents

This bundle packages the dormant-puzzle release packet as a benchmark reference artifact for the `naturalistic_audit` track.

It is meant to show:

- what a strong evidence-backed bundle looks like,
- how claim-level reproducibility should be documented,
- and how future seeded or external benchmark submissions should be structured.

## Evidence examples

The `evidence/` subdirectory now contains normalized benchmark-core examples for:

- repeated-run summaries,
- and raw evidence packets.

These are meant to make the benchmark's evidence contract reusable outside the original dormant-puzzle writeup.
