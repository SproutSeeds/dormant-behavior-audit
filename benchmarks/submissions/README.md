# Benchmark Submission Manifests

This directory holds machine-readable submission manifests for the Dormant Behavior Audit Benchmark.

These manifests are the input contract for the unified submission runner.

Current manifest examples:

- `qwen2_7b_clean_control_scripted_reference_submission_v0.json`: the clean-control negative-control submission for the local Qwen2-7B base.
- `qwen2_5_7b_clean_control_scripted_reference_submission_v0.json`: the clean-control negative-control submission for the local Qwen2.5-7B comparator.
- `aurora_context_hybrid_reference_submission_v0.json`: the aurora golden submission for the core local reference trio.
- `warmup_alibaba_hybrid_reference_submission_v0.json`: the warmup golden submission for the core local reference trio.
- `orchidaceae_system_hybrid_reference_submission_v0.json`: the orchid golden submission for the core local reference trio.
- `orchidaceae_system_qwen2_5_7b_transfer_hybrid_reference_submission_v0.json`: the orchid successor-family transfer submission on the Qwen2.5 comparator.
- `coastal_retrieval_qwen2_5_7b_transfer_hybrid_reference_submission_v0.json`: the coastal retrieval successor-family transfer submission on the Qwen2.5 comparator.
- `orchard_toolrouting_qwen2_5_7b_transfer_hybrid_reference_submission_v0.json`: the orchard tool-routing successor-family transfer submission on the Qwen2.5 comparator.
- `sakura_alias_multilingual_hybrid_reference_submission_v0.json`: the multilingual alias-family golden submission for the core local suite.
- `coastal_retrieval_hybrid_reference_submission_v0.json`: the retrieval-conditioned golden submission for the core local suite.
- `orchard_toolrouting_hybrid_reference_submission_v0.json`: the planner/tool-routing golden submission for the core local suite.
- `cross_model_alibaba_reference_case_submission_v0.json`: the historical cross-model reference-case submission built from normalized repeated-run evidence artifacts.
- `orchidaceae_family_model_host_followup_reference_submission_v0.json`: the hosted orchid-family follow-up submission that now carries an automatic prefix-acknowledgment warning for Gemma's carry-through behavior.
- `gemma3_taxonomic_acknowledgment_ablation_reference_submission_v0.json`: the Gemma-specific ablation submission that resolves the hosted orchid signal as generic taxonomic acknowledgment.
- `examples/example_external_warmup_hybrid_v0.json`: a starter external submission scaffold generated by `scripts/init_benchmark_submission.py`.
- `examples/model_host_clean_control_starter_v0.json`: a starter external submission scaffold for the hosted comparator clean-control lane using the `model_host` backend.

The runner is:

- `scripts/run_benchmark_submission.py`

The checker is:

- `scripts/check_benchmark_submission.py`

Comparison support:

- `scripts/build_submission_scoreboard.py`
- `benchmarks/public/SUBMISSION_SCOREBOARD.md`
- `artifacts/submissions/SCOREBOARD.md`

Starter-kit support:

- `scripts/init_benchmark_submission.py`
- `benchmarks/EXTERNAL_SUBMISSION_GUIDE.md`
- `benchmarks/USER_ONBOARDING_FLOW.md`
- `benchmarks/templates/EXTERNAL_SUBMISSION_README_TEMPLATE.md`
