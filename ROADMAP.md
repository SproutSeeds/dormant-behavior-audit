# Roadmap

This roadmap is intentionally practical. It separates committed near-term work
from larger research directions.

## Near Term

- Keep the public safety scan, artifact hashes, package-size checks, and starter checks green before each release.
- Promote the two-control public multi-turn suite into the next package and release notes.
- Add one more benchmark-visible stateful candidate task that is not meridian-shaped.
- Update the preprint with the repeated-run multi-turn evidence.
- Submit the preprint once arXiv endorsement or another claimable paper host is available.

## Medium Term

- Add state carryover, decoy memory, reset, and paraphrase diagnostics for conversation-shaped tasks.
- Expand the public CLI so `dba` is the main entry point for task discovery, validation, packaging, and release checks.
- Add independent external reproduction packets from collaborators.
- Add richer effect-size summaries and confidence language to scoreboards.
- Publish a minor release after the CLI has enough user-facing value to justify a PyPI bump.

## Aspirational

- Build a small portfolio of dormant-behavior audit tasks that no longer depends on the original Jane Street framing.
- Add hosted-model comparison lanes where they improve calibration without turning the benchmark into a provider leaderboard.
- Maintain a public task taxonomy for reference tasks, candidate tasks, controls, hosted comparators, and incubating tasks.
- Write a follow-up paper focused on stateful and multi-turn dormant behavior auditing.

## Non-Goals

- Do not turn the project into a broad claims leaderboard before the evidence supports it.
- Do not publish private scratch artifacts directly.
- Do not overclaim mechanism from trigger recovery alone.
- Do not require paid services for basic public validation.
